# 产品需求文档

## 项目目标

建立一个极简、稳定、可长期维护的静态个人思想网站。首页用卡片展示母题/项目入口，每个入口进入后是一组会不断生长、互相引用、互相跳转的 HTML 页面。

## 用户需求

- 站长需要记录不成熟但值得追踪的想法
- 想法可以不断生长、分叉、修正
- 访问者可以按想法之间的链接关系自由浏览

## 功能范围

- 首页卡片布局
- 母题入口页面
- 子页面（普通文章页面）
- 页面之间超链接跳转
- 自动深色模式（跟随系统）
- 静态 CSS，无运行时 JS

## 不做什么

- 评论系统
- 登录系统
- 后台管理系统
- 数据库
- 搜索
- 标签筛选
- 动态加载文章列表
- 无限滚动
- 点赞收藏
- SPA 单页应用路由
- React / Vue / Next.js

## 验收标准

1. 首页可访问，有标题和简介
2. 首页有至少 1 个母题卡片
3. 点击卡片进入母题入口页
4. 母题入口页链接至少 1 个子页面
5. 子页面可返回母题入口和首页
6. 页面跳转不依赖 JavaScript
7. 页面在手机和桌面均可阅读
8. 页面支持自动深色模式
9. CSS 是编译后的静态文件
10. 不使用数据库、评论系统、前端框架
