# AI 协作流程

## 判断：新建母题还是新建子页面

### 新建母题的条件
- 这个想法足够大，可以长期展开
- 它会衍生多个问题
- 它和已有母题关系不强
- 它适合作为首页卡片入口

### 新建子页面的条件
- 它是某个旧想法的延伸
- 它是在回答旧页面里的一个问题
- 它是某个母题下的实验、反驳、补充、资料整理

## 新建母题流程

1. 创建目录：`thoughts/{slug}/`
2. 创建入口页：`thoughts/{slug}/index.html`（参考 `templates/thought-index.html`）
3. 在首页 `index.html` 添加卡片（参考 `templates/home-card.html`）
4. 在入口页写原始想法
5. 预留"已经生长出的页面"区域
6. 如果已有第一个子问题，同时创建第一个子页面

## 新建子页面流程

1. 确定所属母题
2. 创建 `{page-slug}.html`（参考 `templates/thought-page.html`）
3. 页面顶部加面包屑导航
4. 正文中加入相关内部链接
5. 页面底部加入"回到母题入口"
6. 回到母题入口页，添加该子页面链接
7. 如有必要，在相关旧页面里添加反向链接

## 页面更新流程

当旧想法被修正时，不覆盖原文。新增"后来修正"段落，链接到新页面。

## 输出前检查清单

1. 是否使用了完整 HTML 文档结构？
2. `lang="zh-CN"` 是否存在？
3. `meta viewport` 是否存在？
4. CSS 路径是否按当前页面层级写对？
5. 所有内部链接是否为相对路径？
6. 是否误用了根路径 `/xxx`？
7. 是否误用了 JavaScript？
8. 是否支持 `dark:` 深色样式？
9. 是否有返回首页链接？
10. 是否有返回母题入口链接？
11. 页面标题是否清晰？
12. 是否新增了必要的反向链接？
13. 是否更新了母题入口页？
14. 首页是否只在新母题时更新？
