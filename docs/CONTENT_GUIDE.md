# 内容写作规范

## 什么是母题

母题是一个值得长期追踪的大想法。它会衍生多个子问题。母题在首页有卡片入口。

## 什么是子页面

子页面是母题下的具体分支——可能是对某个问题的分析、实验设计、反例、资料整理、结论修订。子页面通过正文中的链接互相连接。

## 如何命名页面

- 文件名使用语义化英文 slug：`file-vs-chat.html`
- 页面标题保留中文：`<h1>文件输出和网页回答到底有什么差异？</h1>`
- 文件名负责稳定，标题负责表达

## 如何写原始想法

直接记录直觉、问题、困惑。不要过度包装。这个网站的价值是记录"想法如何变化"，而不是展示"完美的最终结论"。

## 如何写更新记录

当旧想法被修正时，不覆盖原文。在页面底部新增"后来修正"段落，链接到新页面。

## 如何添加内部链接

- 同目录：`<a href="./page.html">`
- 返回母题入口：`<a href="./index.html">`
- 返回首页：`<a href="../../index.html">`
- 跨项目：`<a href="../other-thought/index.html">`
